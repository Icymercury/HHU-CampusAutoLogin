# 河海大学校园网自动登录

一个轻量的 Windows 小工具，开机后自动完成 ePortal 认证，不用再打开浏览器手动点登录。

> 适用于河海大学校园网（锐捷 ePortal）。其他学校可参考「适配其他学校」一节。

---

## 特点

- **开机自动登录** — 采用「启动时」触发器，不输 PIN 也会执行
- **图形界面** — 输入一次学号密码即可，密码框带显示切换，方便核对
- **密码加密存储** — 使用 Windows DPAPI 机器级加密，明文不落盘
- **不打扰** — 检测不到校园网就静默退出，回家、去咖啡厅不会弹窗
- **改密提醒** — 连续登录失败会在界面提示重新输入
- **零第三方依赖** — 纯 Python 标准库实现，不依赖 Selenium 或浏览器驱动

---

## 使用方法

### 1. 下载

到 [Releases](../../releases) 页面下载 `CampusAutoLogin-v1.0.zip`。

### 2. 解压

解压到任意目录，建议不要放在 C 盘根目录或路径含特殊字符的地方。

解压后结构：

```
CampusAutoLogin/
├── CampusAutoLogin.exe     主程序
├── runtime/                运行库，不要删也不要单独移动
├── 使用说明.txt
└── 安装开机自启.bat         备用入口
```

### 3. 首次配置

双击 `CampusAutoLogin.exe`，会弹出设置窗口：

- 学号：你的校园网账号
- 密码：校园网登录密码（默认显示为 `*`，点「显示」可核对）
- 运营商：默认「中国移动」，按你实际开通的选择

点「保存」。

### 4. 安装开机自启

在主界面点「安装自启」，系统会弹出 UAC 授权，选「是」。

完成后状态应显示 **开机自启：已启用**。

### 5. 验证

点「立即登录」手动跑一次，观察下方日志。或者直接重启电脑，等半分钟看网络是否已连通。

## 常见问题

### Windows 提示「未知发布者」，无法运行

**这是正常现象，不是病毒。**

本项目是个人开源项目，没有购买代码签名证书（一年数千元）。任何未签名的 exe 都会触发 Windows SmartScreen。

处理方式：点 **「更多信息」→「仍要运行」**。

### 杀毒软件报毒

**同样是误报。** 打包工具 PyInstaller 生成的程序在国内杀软的启发式规则里命中率偏高。

在 VirusTotal 上，60+ 个引擎中通常只有 1–2 个小众引擎报告，属于典型的误报特征。

如被拦截，请将整个文件夹加入白名单。

### 开机后没有自动登录

按顺序排查：

**1. 确认自启已安装**

打开程序，看「开机自启」是否为 **已启用**。如果显示「需更新」，点一下按钮重新安装。

**2. 关闭 Windows 快速启动（最常见原因）**

控制面板 → 电源选项 → 选择电源按钮的功能 → 更改当前不可用的设置 → 取消勾选 **「启用快速启动」**

原因：快速启动本质是休眠而非真正关机，系统的「启动时」事件不会触发，任务计划里的开机任务自然不执行。这个坑很多人踩。

**3. 看日志**

`logs/` 目录下按日期存放日志，里面记录了每一步的检测结果：

- `等待接入校园网...` → 开机时网卡还没就绪，属正常
- `超时未检测到校园网，退出` → 判定不在校园网范围，静默退出
- `登录返回: {...}` → 认证接口的原始返回，可按此判断失败原因

### 修改了校园网密码

打开程序 →「设置」→ 重新输入密码 → 保存。

如果连续 3 次自动登录失败，主界面顶部会出现红字提醒。

### 换了一台电脑

配置与本机绑定（使用机器级 DPAPI 密钥），换电脑需要重新输入一次密码。重新解压一份、重新点「安装自启」即可。

### 怎么卸载

打开程序 →「设置」→ 点「**移除自启**」。这会删除计划任务，程序文件保留，仍可手动打开使用。

要彻底删除，移除自启后再删除整个文件夹。

> 直接删文件夹而不先移除自启，会在系统里留下一条指向空路径的计划任务。不影响使用，但不干净。

### 移动了文件夹之后开机不自启

任务计划里存的是绝对路径，移动文件夹会导致任务失效。

程序会在启动时对比记录的安装路径和当前路径，不一致就会在界面顶部提示「程序所在路径已变更」，此时点「更新自启」重新创建即可。

### 一直显示「未认证」但能上网

部分网络对探测地址有白名单放行。此时点「立即登录」即可，不影响正常使用。

## 工作原理

不依赖浏览器自动化，直接复现认证请求：

1. **探测在线状态** — 访问 HTTP 探测地址，检查响应内容中是否包含 portal 地址
   （注意：未认证时网关不一定返回 302，很多部署是返回 200 + JS 跳转，只看状态码会误判）

2. **获取会话参数** — 从跳转页面中提取本次会话的 `wlanuserip`、`mac`、`nasip` 等参数
   （这些值每次开机都不同，必须动态获取）

3. **提交认证** — 向 `InterFace.do?method=login` 提交账号密码与会话参数

4. **复验** — 再次探测确认已上线，失败则按配置重试

相比 Selenium 方案的优势：不需要 chromedriver、不受浏览器版本影响、不受登录页面改版影响、启动速度快一个数量级。

## 适配其他学校

本工具针对河海大学的锐捷 ePortal 编写。如果要在其他学校使用：

1. 修改 `config.json` 中的 `host` 为对应学校的认证门户地址
2. 抓包确认登录接口路径与参数名（不同版本差异较大）
3. 确认是否需要 `passwordEncrypt`（部分学校开启了 RSA 加密）

不同学校的认证系统差异很大，不能直接套用。

## 自行构建

```bash
pip install pyinstaller
pyinstaller --noconfirm --onedir --windowed \
  --name CampusAutoLogin \
  --contents-directory runtime \
  auto_login.py
```

产物在 `dist/CampusAutoLogin/`。

建议使用 `--onedir` 而非 `--onefile`：单文件模式会在运行时自解压到临时目录，这个行为与自解压木马高度相似，误报率显著更高。
